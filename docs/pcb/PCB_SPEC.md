# 캐리어 PCB 설계 사양서 (v0.1 — 승인 대기)

Arduino Nano ESP32 를 꽂아 쓰는 50 × 70 mm 센서 캐리어 보드. 사육장 센서 → Firebase(`/sensor/latest`, `/events`) 업로드용.
배치도: `pcb-floorplan.html` (축척 1:1 비율 SVG)

## 1. 요구사항 요약

| 항목 | 사양 |
|---|---|
| 보드 | 50 × 70 mm, 2층, 1.6 mm, 모서리 R2, M3 구멍 4개 |
| MCU | Arduino Nano ESP32 (ABX00083) 2×15 암 소켓 |
| 센서 | SHT31 온습도(I2C, 케이블 프로브), 진동(D2), 리드 스위치(D3) |
| 입력 | 버튼 3개(D4~D6), 상태 LED(D7) |
| 전원 | USB-C 5V + 퓨즈 |
| 커넥터 | JST-PH 2.0 mm (센서 3개 + 선택 LED 1개) |
| 조립 | 수작업 납땜 가능 패키지 기본 (0805 / SOD-123 / SMA) |

## 2. 사육장 사진에서 반영한 조건

| 관찰 | 설계 영향 |
|---|---|
| 상단에 분무 노즐(검은 배관), 벽면에 물방울 | SHT31 은 **PTFE 멤브레인 방수 프로브** 사용, 노즐 직사 위치 회피. 보드는 **사육장 밖** 설치 |
| 문 오른쪽에 자석 래치, 왼쪽 하단 경첩 | 리드 스위치 = 래치 쪽 문틀, 자석 = 문. 열림/닫힘 이벤트 |
| 아크릴 박스, 바닥 키친타월 | 진동 센서는 박스 측면 외벽에 부착(바닥 직접 접촉 금지) |
| 왼쪽 벽 콘센트 + USB 충전기 | USB-C 5V 어댑터 접근 가능 → 전원 입력은 보드 하단 가장자리 |
| 습기 많은 환경 | 보드는 외부 설치라도 **방습 코팅(컨포멀)** 가능하게 커넥터/버튼 마스크 개방 영역 지정 |

## 3. 핀 맵 (Arduino 핀 이름 기준)

| 신호 | Nano 핀 | 헤더 | 연결 | 비고 |
|---|---|---|---|---|
| I2C SDA | A4 | 좌열 8번 | J2-2 | 4.7 kΩ 풀업 |
| I2C SCL | A5 | 좌열 9번 | J2-3 | 4.7 kΩ 풀업 |
| 진동 | D2 | 우열 11번 | J4-3 | `INPUT_PULLUP` |
| 리드 | D3 | 우열 10번 | J3-2 | `INPUT_PULLUP` |
| 버튼 1 | D4 | 우열 9번 | SW1 | `INPUT_PULLUP`, 100 nF |
| 버튼 2 | D5 | 우열 8번 | SW2 | 〃 |
| 버튼 3 | D6 | 우열 7번 | SW3 | 〃 |
| 상태 LED | D7 | 우열 6번 | LED1 (+ 선택 J6) | 330 Ω, 약 4 mA |
| 3V3 | 3V3 | 좌열 2번 | 센서 전원 | |
| 5V 공급 | VBUS | 좌열 12번 | JP1 경유 | §4 참고 |
| GND | GND | 좌열 14번, 우열 12번 | | |

헤더 순서(USB-C 가 위, 위→아래): 좌열 D13, 3V3, B0, A0~A7, VBUS, B1, GND, VIN / 우열 D12~D2, GND, RST, D0, D1.
**D2~D7 은 GPIO5~10 으로 추정**(D2=GPIO5, D5=GPIO8 만 자료로 확인). 모두 스트래핑 핀(0/3/45/46)이 아니어서 부팅 간섭이 없는 구성입니다. 펌웨어에서는 GPIO 번호가 아닌 `D2` 같은 핀 이름을 사용합니다.

## 4. 전원 설계

```
USB-C(CC1/CC2 5.1kΩ) → F1(PTC) → D1(쇼트키) → JP1 → Nano VBUS
                    └ TVS(5V) ┘                     Nano 3V3 → J2/J4 센서 전원, 풀업
```

| 부품 | 사양 | 이유 |
|---|---|---|
| F1 | 1206 PTC, 유지 0.5~0.75 A | ESP32 Wi-Fi 피크 약 0.3 A + 여유. 단락 보호 |
| TVS | 5V 단방향, SOD-123FL 또는 SMA | 어댑터 서지 |
| D1 | 쇼트키 1 A (SS14 급) | Nano 쪽 USB 와 동시 연결 시 **역류 차단** |
| JP1 | 솔더 점퍼(기본 **개방**) | VBUS 외부 급전 가능 여부가 자료에서 미확인 → 검증 후 닫음 |
| R_CC | 5.1 kΩ × 2 | USB-C 5V 협상(전원 전용 소스 인식) |
| C | 10 µF + 100 nF (VBUS 측) | 안정화 |

- 5V 는 Nano VBUS 로만 가고, 센서는 모두 Nano 3V3 로 구동합니다.
- **JP1 을 닫기 전**에 ABX00083 회로도에서 VBUS 핀 외부 급전 시 보호 구조를 확인합니다. 불확실하면 JP1 을 열어 두고 **Nano 자체 USB-C 로 전원 공급**합니다(보드 상단 가장자리 돌출).

## 11. 실패 방지 체크리스트

1. **JP1(VBUS 급전)을 확인 전에 닫지 마세요.** 외부 5V 와 모듈 내부 전원이 충돌할 수 있습니다.
2. **안테나 구역에 동박·부품을 두지 마세요.** Wi-Fi 감도가 크게 떨어집니다.
3. **SHT31 은 방수 프로브로, 분무 직사 위치를 피하세요.** 일반 브레이크아웃은 물방울에 쉽게 오염됩니다.
