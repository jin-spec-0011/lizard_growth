# 캐리어 PCB 설계 사양서 v0.2 — 주문 제작(부품 장착 포함)

Arduino Nano ESP32 를 꽂아 쓰는 50 × 70 mm 센서 캐리어 보드. 사육장 센서 → Firebase 업로드용.
**수작업 납땜 없이**, PCB 제작 + 표면실장(SMT) 조립까지 업체에 맡기는 것을 전제로 설계했습니다.

| 산출물 | 파일 |
|---|---|
| 회로도(넷 라벨 방식) | `schematic.html` / `schematic.svg` |
| 배치도(전 부품, 축척) | `pcb-floorplan.html` / `floorplan.svg` |
| 부품표 | `bom.csv` (35행, 42 SMT + 2 THT + DNP 4) |
| 넷리스트 | `netlist.csv` |
| 데이터 원본 | `tools/pcb/design.py` (ERC·배치 검사: `python3 tools/pcb/design.py --check`) |

## 1. v0.1 에서 바뀐 점 (중요)

| 항목 | v0.1 | v0.2 | 이유 |
|---|---|---|---|
| 전원 경로 | USB-C 5V → 퓨즈 → 쇼트키 → Nano `VBUS` | USB-C 5V → PTC → **MT3608 승압 9V → Nano `VIN`** | `VBUS` 는 USB 연결 시에만 5V 가 나오는 **출력 전용**. 외부 5V 연결 시 보드 손상 가능 ([Arduino 지원 문서](https://support.arduino.cc/hc/en-us/articles/360014779679-Supply-USB-power-via-the-VUSB-VBUS-or-5V-pin-on-Nano-boards)). `VIN` 허용 범위는 6~21V ([데이터시트](https://docs.arduino.cc/resources/datasheets/ABX00083-datasheet.pdf)) |
| `VBUS` 핀 | JP1 경유 연결 | **NC** | 위와 동일 |
| 패키지 | 0805 위주(수작업) | 0603 위주(기계 조립) | 주문 제작 |
| 커넥터 | JST-PH THT | JST-PH **측면 SMD** | 조립 단순화 |
| 센서 | 외부 프로브만 | 외부 프로브 + 온보드 SHT31 풋프린트(DNP) | 실내 기준값 비교용 선택 |

## 2. 회로 블록

| 블록 | 구성 | 핵심 값 |
|---|---|---|
| ① 입력·보호 | USB-C 6P(J1), CC 5.1kΩ×2, PTC(F1), TVS 5V(TVS1), 22µF+100nF, 전원 LED | PTC 유지 0.75A |
| ② 승압 | MT3608(U2), 22µH(L1), SS34(D2), 피드백 100k/7.15k, 22µF×2, 0Ω(R17), TVS 15V(TVS2) | **Vout = 0.6×(1+100k/7.15k) = 8.99V** |
| ③ Nano | 1×15 암 소켓 ×2, 테스트 패드 4개(5V/9V/3V3/GND) | `VBUS`=NC, `VIN`=9V |
| ④ 센서 입력 | J2(I2C), J3(리드), J4(진동), ESD 어레이 ×2, 풀업·직렬·디바운스 | I2C 4.7kΩ 풀업, 33Ω 직렬 |
| ⑤ UI | 버튼 3개(+100nF), 상태 LED, 외부 LED 커넥터(DNP) | LED 330Ω ≈ 4mA |

### 핀 맵 (Arduino 핀 이름 기준)
| 신호 | 핀 | 헤더 위치 | 연결 |
|---|---|---|---|
| I2C SDA / SCL | A4 / A5 | 좌 8 / 9 | J2 (R5/R6 33Ω 경유) |
| 진동 | D2 | 우 11 | J4 (R8 1kΩ, 10kΩ 풀업, 100nF) |
| 리드 | D3 | 우 10 | J3 (R7 1kΩ, 10kΩ 풀업, 100nF) |
| 버튼 1/2/3 | D4 / D5 / D6 | 우 9 / 8 / 7 | SW1~3 (100nF) |
| 상태 LED | D7 | 우 6 | LED1 (R11), J6(DNP) |
| 3V3 / GND / VIN / VBUS | — | 좌 2 / 14, 우 12 / 좌 15 / 좌 12 | 센서 전원 / 접지 / **9V 입력** / **NC** |

- 부스트 출력은 TVS2(SMAJ15A)로 보호합니다. 피드백 상단 저항이 개방되는 고장에서 전압이 오르더라도 Nano `VIN` 최대 21V 를 넘지 않게 클램프하고, 지속되면 PTC 가 차단합니다.
- **9V 는 Nano 내부 강압기가 3.3V 로 변환**합니다. 센서는 모두 Nano 3V3 로 구동합니다.
- 승압 IC(1.2 MHz)는 안테나 금지 구역에서 약 20 mm 떨어진 좌하단에 배치했습니다.

## 3. 사육장 쪽 센서부 (보드 밖, 별도 구매)

| 구분 | 사양 | 커넥터 |
|---|---|---|
| 온습도 | SHT31 **방수 프로브**(PTFE 멤브레인, 4선 I2C, 케이블 ≤ 1 m) | J2 (3V3/SDA/SCL/GND) |
| 문 열림 | 리드 스위치(NO, 건접점) + 자석, 문 래치 쪽 문틀/문에 부착 | J3 (SIG/GND) |
| 진동 | 2단자 볼 스위치(예: SW-18010P) 또는 SW-420 모듈(3V3 구동) | J4 (3V3/GND/SIG) |
| 케이블 | JST-PH 하우징 + 압착 케이블(4/2/3핀) 또는 기성 케이블 조립품 | — |
| 전원 | 5V USB-C 어댑터 ≥ 1A(PD 어댑터도 5V 로 동작) + USB-C 케이블 | J1 |
| 고정 | M3 스탠드오프 4개 | 장착 구멍 4개 |

- 분무 노즐 직사 위치와 물방울이 맺히는 벽면은 피하고, 케이블에 드립 루프(아래로 늘어뜨린 구간)를 둡니다.
- 센서 위치 도면은 `pcb-floorplan.html` 의 ②를 참고하세요.

## 4. 제조·조립 사양 (주문서에 그대로 입력)

| 항목 | 값 |
|---|---|
| 기판 | FR4, 2층, 1.6 mm, 50 × 70 mm, 모서리 R2 |
| 구리 | 1 oz, 최소 선폭/간격 0.2 mm(설계 0.25), 비아 0.3/0.6 mm |
| 표면 처리 | 무연 HASL(기본) 또는 ENIG(방습·평탄도 우선 시) |
| 장착 구멍 | M3(Ø3.2) ×4, 모서리 (3.5, 3.5) 기준 |
| 피듀셜 | 3개(Ø1.0 구리, 마스크 개구 Ø2.0) |
| 조립 | 상면 SMT 42점, **THT 2점(Nano 소켓)**, DNP 4점(U3, C12, J6, R12) |
| 필요 파일 | Gerber, 드릴, BOM(`bom.csv`), 부품 좌표(CPL) — KiCad 단계에서 생성 |

- THT 소켓 2점은 **THT 조립을 지원하는 옵션/업체**에서 같이 맡깁니다. 지원하지 않으면 (a) SMD 암 소켓으로 변경하거나 (b) 소켓 없이 주문 후 직접 장착하는 두 가지가 있으며, 어느 쪽이든 견적 시 확인하세요.
- JLCPCB/LCSC 등 부품 번호는 주문 시점 재고 기준으로 매핑해야 해서 `bom.csv` 의 마지막 열을 비워 뒀습니다. 사양(값·패키지·MPN 예시)은 채워져 있습니다.

## 5. 검증 결과와 남은 확인 항목

| 구분 | 내용 |
|---|---|
| 자동 검사 통과 | ERC 0건(고아 넷·중복 핀·필수 넷·`VBUS`=NC·부스트 출력 8.99V), 배치 겹침 0건(보드 밖, 모듈 아래, 안테나 구역, 장착 구멍, 피듀셜, 간격 0.2 mm) |
| 검사 동작 확인 | 일부러 넣은 겹침·안테나 침범·`VBUS` 오배선·고아 넷이 모두 검출됨 |
| 확인 필요 | ① 헤더 핀 순서와 D2~D7/A4·A5 의 GPIO 번호(D2=GPIO5, D5=GPIO8 만 자료 확인) ② 안테나 위치와 금지 구역 범위 ③ 소켓 간격 15.24 mm·모듈 외형 ④ SHT31-DIS 핀 배열(DNP 부품) ⑤ 승압 회로의 EMI 가 Wi-Fi 에 미치는 영향(시제품에서 확인) ⑥ Nano USB-C 와 `VIN` 동시 급전 시 동작(미확인) |
| 한계 | KiCad 가 이 환경에 없어 **배선(트레이스)·DRC·Gerber 는 아직 없습니다.** 배치까지가 검증된 범위입니다. |

## 6. 다음 단계

| 단계 | 내용 |

## 7. 실패 방지 체크리스트

1. **프로그래밍·디버깅용으로 Nano USB-C 를 꽂을 때는 캐리어 USB-C 전원을 분리하세요.** 두 전원 동시 연결 시 동작은 확인되지 않았습니다. 불가피하면 R17(0Ω)을 제거할 수 있게 해 두었습니다.
2. **시제품 첫 전원 인가 전에 TP2(9V)를 멀티미터로 확인하세요.** 8.5~9.5V 가 아니면 Nano 를 꽂지 마세요(승압 피드백 저항 오장착이 가장 흔한 실수).
3. **주문 직전에 THT 소켓 조립 가능 여부와 DNP 4점이 장착되지 않는지 BOM 을 재확인하세요.**
