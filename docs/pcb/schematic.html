전원 설계 변경: Nano ESP32 의 VBUS 는 USB 연결 시에만 5V 가 나오는 출력 전용 핀이라 외부 5V 를 넣을 수 없습니다. USB-C 5V 를 MT3608 로 9V 승압(Vout=0.6×(1+100k/7.15k)=8.99V) 해 VIN(허용 6~21V)으로 공급하고, VBUS 는 NC 입니다. 부스트 고장 시 보호용 TVS(SMAJ15A)를 VIN 에 둡니다.
GND+3V3+5V / VBUS_IN+9V / VINI2C리드·진동버튼LEDNC
Nano 미사용 핀(NC): D13, B0, A0, A1, A2, A3, A6, A7, B1, D12, D11, D10, D9, D8, RST, D0, D1 — 확장 시 사용. 펌웨어 핀: SDA=A4, SCL=A5, 진동=D2, 리드=D3, 버튼=D4~D6, LED=D7. I2C 주소: 케이블 프로브 0x44, 온보드 U3(선택) 0x45.
